# 双副牌扑克游戏平台

一个可扩展的网页扑克游戏平台。首个游戏是单人本地掼蛋，后续将增加移动/PWA、多人掼蛋与拖拉机 80 分。

## 当前状态

P1-01 前端工程初始化已验收；掼蛋规则仍处于 P0 待确认状态，因此尚未实现任何游戏规则或牌桌 UI。后续任务的执行顺序与验收条件见 [P1-P3 执行计划](proj-info/phases/P1-P3-execution-plan.md)。
