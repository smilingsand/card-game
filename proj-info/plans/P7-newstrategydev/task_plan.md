# P7：基于公开信息的 normal-vNext 策略升级计划

## 目标

在不恢复 P2.5 expert/master 路线、不改变 `guandan-v5` 规则、也不扩大机器人可见信息的前提下，分步将上游项目中可取的协同、控牌、炸弹经济和残局路线评估思想，重构为 `@card-game/guandan-core` 内可重放、可解释、可验证的 normal-vNext 策略能力。

## 范围与硬约束

- 产品策略仍只有 `normal-vNext`；不增加 easy/medium/hard/master UI 或配置。
- 不复制上游 `guandan-windows` 策略源码；仅将策略思想以本项目的领域模型重新实现。
- 策略只接收 `BotView`：己方手牌、公开事实、公开剩余张数、当前桌面状态和规则层生成的合法动作；不得读取对手手牌、洗牌 seed、未发牌或隐藏评估。
- 规则识别、比较和合法动作只能来自 `packages/guandan-core`；策略层不得重建它们。
- 同一 `BotView` 必须产生同一动作和解释；不使用 `Math.random()`、时钟截止或模块级可变记忆。
- 每个任务都须先增加固定牌例或失败回归，再实现最小改动；每个任务独立提交。
- P2.5 的 expert/master 路线保持撤销。任何未来恢复提议必须先新增 ADR，且不属于本计划。

## 当前阶段

P7-05 的本地收敛证据已完成：normal-vNext 对固定 seed `0, 1, 7, 42, 99` 的首次决策均
合法，且单次决策低于 5 秒。未加入搜索、概率模型或新产品难度；Preview 与 Production
验收尚未执行，因此该任务处于 `ready_for_acceptance`，而非已发布。

## 决策与待确认项

| 决策                           | 理由                                                |
| ------------------------------ | --------------------------------------------------- |
| 先 observation，后策略         | 记牌和赛局策略必须有可审计的公开事实输入。          |
| 搜索只评估己方手牌路线         | 在 P3/P4 个人投影下安全、确定，且避免上游窥牌实现。 |
| 保持 normal-vNext 单一产品档位 | 符合当前产品边界和用户要求，避免恢复 P2.5。         |
| 不以短样本胜率验收             | 策略回归必须同时看固定牌例、合法性、解释与性能。    |

| 候选组合爆炸         | 始终从规则层候选集开始，并设固定节点/候选上限和性能测试。     |

| 策略变弱或不可解释   | P7-00 可独立回退；未获得固定牌例和人工审阅证据不得发布。      |
