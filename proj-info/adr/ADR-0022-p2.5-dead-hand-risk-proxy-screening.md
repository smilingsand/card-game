# ADR-0022：P2.5 DeadHandRiskProxy 深度入围

- 状态：accepted
- 日期：2026-07-18
- 决策人：产品负责人
- 关联：ADR-0021、P2.5-16

## 决策

expert-24 的 ordinary 深度名额不扩大，改为确定性的双通道入围：

1. 18 个按 `lightBaseScore descending` 选取；
2. 6 个从其余 candidate 按 `deadHandRiskProxy ascending` 选取；
3. 去重后不足 24 个，按 `lightBaseScore descending` 补足；
4. mandatory 优先级和 max=32 保持 ADR-0021 不变。

`deadHandRiskProxy` 必须是纯函数、可回放，不得调用完整 PostAction、动作后 HandPlan 或 FollowUp。输入仅限己方手牌、candidate 移除牌、级牌和公开信息；至少反映低散单、控制牌耗尽、炸弹/完整结构破坏和逢人配消耗。

proxy 值、分项、入围通道和筛选原因必须进入 `DecisionExplanation` 与 `DecisionFingerprint`。normal 不变；完整 PostAction/FollowUp 的语义不变。

## 验收

使用 ADR-0020 冻结的同一批 34 个 BotView 对 expert-24 与 `experimental-full` 重做质量对照：

- 动作差异率 <=10%；
- `dead_hand_risk_created` 相对 full 增量 <=1；
- 不得出现尾局阻断或队友协作回退。

未通过不得扩大深度预算、进入性能门禁或启动 P2.5-17。
