# ADR-0004：掼蛋牌型与逢人配解释模型

- 状态：已接受
- 日期：2026-07-13

## 决策

1. 识别器输入为只读实体 `Card[]` 与当前 `levelRank`；红桃 `levelRank` 是逢人配，大小王永不为逢人配。
2. 识别器返回零个或多个不可变解释。解释仅记录每张逢人配的目标普通牌投影，绝不修改输入 Card 的 `id`、`suit` 或 `rank`。
3. 每个合法解释均返回统一牌型和比较所需的键；比较器本身留待 P1-07。无合法解释返回稳定错误码，不抛出规则异常。
4. 连续牌型使用冻结规则的 A 低端与高端两种线性窗口；逢人配可投影到任意非王普通点数/花色。

## 后果

牌型或解释语义变更须新增 ADR 并更新 `rulesVersion`。P1-06 不实现出牌合法性、压制比较、回合或结算。
