# ADR-0007：掼蛋结算、进贡与下一局初始化

- 状态：已被 ADR-0002、ADR-0011 与 ADR-0012 取代
- 日期：2026-07-13

## 决策

这是 P1-09 的历史结算草案。当前实现使用 `guandan-v4` / schema 4，由 `TableSession` 记录连续多局事件；首局南家领出，级牌取上一局头游方升级后的等级。双上/头三/头末仍分别升 3/2/1；单下、双下、两王抗贡、同点首出和还贡限制以 `docs/resolved-rules.md` 与 ADR-0011、ADR-0012 为准。

## 后果

P1-09 不实现机器人、UI 或网络协议；旧 rulesVersion 不得静默重解释。
