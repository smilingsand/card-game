# ADR-0027：P3 匿名身份、房间访问与显示名

- 状态：accepted
- 日期：2026-07-23
- 决策者：产品负责人

## 决策

P3 不引入账号。首次进入时，服务端签发不可预测的匿名身份与轮换重连令牌；令牌是授权凭证，显示名绝不是。生产令牌使用 `Secure`、`HttpOnly`、`SameSite=Lax` Cookie，并在 P3-12 使用同站点自定义域名；令牌只存服务端哈希值，轮换后旧令牌立即失效。日志、错误、事件与浏览器可见投影均不得输出令牌原文。

房间是不可列举的邀请制房间：创建时产生至少 128 位 CSPRNG 邀请码，服务端仅保存其带密钥哈希。持有邀请码可在等待/准备阶段请求加入；入座需由服务端绑定匿名身份，且每房间仅一席。创建者是房主，可在未开局时踢出真人、批准换座与开始；房主离开前可转交房主，未转交时保留其席位至重连窗口结束。开局后禁止新真人加入或换座；断线/超时交接留给 P3-08。

真人可从固定名称池选择：曹操、刘备、孙权、周瑜、诸葛亮、关羽、张飞、赵云、貂蝉、小乔、甄宓；也可使用自定义显示名。自定义名称先 NFKC 规范化、去首尾空格并合并内部空格，必须是 2–16 个 Unicode 码点，只含字母、数字和内部单个空格，不能含控制/零宽字符、标记或 HTML。房内比较键为规范化后不区分大小写值，必须唯一。名称仅用于显示；未被真人占用的座位没有名称选择流程，始终由 `normal-vNext` 控制。

## 后果

- P3-03 负责 Cookie、令牌轮换、邀请码哈希和输入 schema；P3-05 负责席位状态机；P3-07 只显示服务端返回的显示名。
- 名称策略的最小固定 POC 位于 `backend/poc/name-policy.*`，不是生产认证实现。
- 若未来要支持公开房间、好友关系或真实账号，必须新增 ADR，不能复用显示名作为权限。
