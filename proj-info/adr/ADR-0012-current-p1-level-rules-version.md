# ADR-0012：P1 当前级牌来源与规则版本

- 状态：已接受
- 日期：2026-07-14
- 决策人：产品负责人

## 背景

连续多局接入后，曾将下一局级牌错误地绑定到下一局先出方所属队。产品澄清：先手由进贡规则决定，而级牌必须反映上一局头游方升级后的等级。这两项事实必须分离，且旧存档不得以新规则重放。

## 决策

1. 首局双方等级均为 2，南家首出，级牌为 2。
2. 从第二局起，双方等级按上一局完成顺序结算；只有头游所属队升级，双上/头三/头末分别升 3/2/1。
3. 当前局级牌恒为上一局头游所属方**升级后的等级**，与进贡后确定的本局先手无关。
4. 先手规则独立执行：单下由进贡者先出；双下由较大贡牌者先出、同点由头游下家先出；抗贡时头游先出。
5. 当前规则版本为 `guandan-v4`，存档 schema 为 4；旧版本明确拒绝恢复，不进行静默迁移。

## 后果

- ADR-0002 中“级牌取先出方所属队等级”的表述失效。
- 文档、固定牌例、桌面显示排序、级/配标识及进贡校验均以本 ADR 与 `docs/resolved-rules.md` 为准。
