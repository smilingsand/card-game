# ADR-0001：P0 掼蛋规则冻结

- 状态：已接受；第 1 条已被 ADR-0011 替代
- 日期：2026-07-13
- 决策人：产品负责人

## 背景

`docs/resolved-rules.md` 原有六项待确认规则，阻止 P1 的正式规则实现。现根据产品负责人确认，将它们固定为可实现、可测试的规则口径。

## 决策

1. 首局固定由东家领出。**历史决定：已被 ADR-0011 替代，当前实现为南家首局领出。**
2. 进贡完成后，进贡牌较大的一家先出；同点时由头游的下家先出；抗贡时由上游先出。
3. 逢人配可参与构成普通炸弹，最大张数为 10。
4. 红桃级牌未作为逢人配时可按原牌面参与组合；连续牌型允许 `A-2-3-4-5`（A 为最小点）和 `10-J-Q-K-A`（A 为最大点）。
5. 还贡“不大于 10”按当前级牌排序判断。
6. 亮牌只用于抗贡，且必须公开展示两张大王；首个单机版不实现其他亮牌、赛事积分、违规处罚或超时机制。

## 后果

- P0 关闭，P1 可按依赖关系启动。
- 后续规则实现和固定牌例以 `docs/resolved-rules.md`、ADR-0011 及其后的修订为准；冲突时以较新的 ADR 和规则文档为准。
- 任何改变以上规则的需求必须新增 ADR、更新规则文档并递增 `rulesVersion`。
