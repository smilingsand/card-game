# ADR-0011：南家首局领出与规则版本升级

- 状态：accepted
- 日期：2026-07-14

## 背景

P1 桌面真人固定为南座。产品现行体验要求首局也由南家先出，行动方向按南、东、北、西循环。该改动会改变首局动作事件流的合法性，不能让旧存档在新规则下静默重放。

## 决策

1. 新规则版本为 `guandan-v2`。
2. 新对局的首局领出者和当前行动者均为南家；循环顺序为南→东→北→西（与既有环形数组东→北→西→南等价）。
3. 后续局的领出权继续由已冻结的进贡、还贡与接风规则决定；本决策不改变该规则。
4. 仅接受 `guandan-v2` 的本地桌面存档。`guandan-v1` 保存的快照和事件流明确提示规则版本不兼容，用户可选择新局或清除存档。

## 后果

- 规则文档、首局固定牌例和桌面存档测试必须使用南家首出。
- 旧存档不会丢失地被错误解释，但无法在本版本继续对局。
- 方式 A 的手牌自动整理属于 UI 表现，不进入本 ADR 的规则、事件或存档兼容范围。
