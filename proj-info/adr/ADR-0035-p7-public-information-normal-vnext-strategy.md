# ADR-0035：P7 基于公开信息的 normal-vNext 策略演进

- 日期：2026-08-26
- 状态：accepted

## 背景

`guandan-windows` 展示了协同、控牌、炸弹经济、残局路线与记牌等策略方向，
但其实现依赖重复规则、随机性及对手手牌读取，不能直接纳入本项目。

ADR-0014 已冻结机器人只读 `BotView` 的观察边界，ADR-0024 已冻结
normal-vNext 是唯一产品策略，并撤销 P2.5 expert/master 路线。

## 决策

1. P7 只演进 `normal-vNext`；`normal-v1` 仅用于离线历史对照，不新增产品难度、UI 或配置。
2. 新启发式只能消费 `BotView`、规则层给出的 `legalActions` 与公开事件；不得读取对手手牌、未发牌、洗牌 seed 或隐藏评估。
3. 策略选择必须是纯且确定的：同一观察输入得到同一动作和理由；禁止 `Math.random()`、墙钟截止和模块级事实缓存。
4. 策略只对规则层候选动作评分/排序，最终动作继续通过统一 `validateAction` 与 `applyAction`。
5. 每次行为变化先增加固定牌例或失败回归，并与 P7-00 固定 seed 自动对局基线比较；胜率不是单独的发布依据。

## 后果

- 上游项目只能作为策略思想来源，不复制其代码或信息模型。
- P7-01 先补齐公开观察投影；协同、概率、炸弹和残局策略均不得越过该边界。
- 本 ADR 不恢复 P2.5；如未来需要恢复 expert/master，必须另立 ADR 并重新验收。
