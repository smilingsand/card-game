# ADR-0023：P2.5 可重复性能测量合同

- 状态：accepted
- 日期：2026-07-18
- 决策人：产品负责人
- 关联：ADR-0019、ADR-0022、P2.5-16

## Node 自动化主基准

Node/tsx 独立进程是自动化性能门禁：

1. 启动 5 个彼此独立的进程；
2. 每个进程先对固定代表性 BotView 执行 3 次不计时预热决策；
3. 之后测量 ADR-0020 冻结的 34 个 BotView；
4. 每个进程开始测量前，在运行时支持时显式执行一次 GC；单次决策之间不得强制 GC；
5. 报告五个进程平均值的中位数、全部样本的 pooled P95、全局最慢决策及暖缓存 P95；不得选择某个较好进程作为验收结果。

性能门槛保持：平均 <=500ms、P95 <=1.5s、最慢 <=4s、暖缓存 P95 <=400ms。

Vitest 性能数据仅作诊断，不是性能主门禁，因测试运行器的 RPC、转换和 JIT 干扰。

## 浏览器产品体验确认

另以 Chromium 生产构建进行至少 3 个全新浏览器会话，使用固定代表性 BotView，记录从请求决策到动作返回的耗时和主线程阻塞。浏览器数据用于产品体验确认；Node 聚合结果用于自动化回归门禁。

完成本合同后恢复 P2.5-16 Stage 1 验收；暂不运行 100 局，不启动 P2.5-17。
