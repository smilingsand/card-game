# ADR-0021：P2.5 Expert 深度 24 质量门禁

- 状态：accepted
- 日期：2026-07-18
- 决策人：产品负责人
- 关联：ADR-0019、ADR-0020、P2.5-16

## 决策

不接受 ADR-0019 expert-12 的质量结果。版本化 expert 配置改为 `p2.5a-depth-24-v1`：

| profile/configuration | 深度 PostAction + FollowUp 默认 / max |
| --- | ---: |
| expert | 24 / 32 |
| experimental | 32 / 32 |
| `experimental-full` | 全部 / 全部，仅研究对照 |
| normal | 不适用，保持 legacy normal path |

质量对照必须使用 ADR-0020 已冻结的同一批 34 个 seed=0 固定 BotView；不得更换或缩小样本。

## 质量门槛

expert-24 对 `experimental-full` 必须同时满足：

- 最终动作差异率 <=10%；
- `dead_hand_risk_created` 相对 full 的增量 <=1；
- 不得出现明显尾局阻断或队友协作回退。

通过后才可验证性能；不得直接进入 100 局，P2.5-17 仍不得启动。

若 expert-24 未通过：停止继续扩大预算，分析既有 7 个差异局面，优先修订深度入围排序，使低 DeadHandRisk candidate 获得深度评估资格；任何排序语义变更须先新增 ADR。
