# P2.5-07 候选生成 2.0 交付边界

> 状态：`accepted`（2026-07-16）。本文件记录候选完整性与默认策略切换的独立决策，避免 P2.5-07 改变 normal 机器人的既有回归行为。

## 两层入口

- `getLegacyNormalCandidates(...)`：normal profile 的冻结回归入口，保留既有候选范围和 UI/自动对局回归行为。
- `getCompleteLegalCandidates(...)`：规则层完整、确定性且牌型导向的合法动作集合；不依赖 HandPlan、Top-N 或专家 profile，所有候选均再次经统一规则引擎裁决。
- `rankExpertCandidates(...)`：仅重排完整合法集合，不删除或自造动作；使用 HandStructure 和 HandPlan 的来源信息。

完整性入口的目标是覆盖三连对、钢板、合理逢人配、同花顺、四王炸及跟牌解释；它不是默认策略切换开关。normal 仍使用 legacy 入口，专家排序仅作为后续模块的输入。

## 接入时机

P2.5-07 只交付候选完整性。只有 P2.5-08、P2.5-09、P2.5-10、P2.5-11、P2.5-13、P2.5-14、P2.5-15 和 P2.5-17 全部完成并验收后，expert 才可接入机器人与提示并成为默认 profile。

在此之前，任何把完整候选或专家排序静默传给 normal 机器人/提示的改动都必须拒绝；候选完整性、评分选择和默认 profile 切换分别验收。
