# P2.5 验收矩阵

> 历史归档，已于 2026-07-22 撤销。P2.5 验收矩阵不再作为发布或性能门禁。

| 类别             | 关键验证                                                                                    | 通过条件                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 规则引擎边界     | 策略输入/输出类型、候选到 validate/apply 的端到端测试                                       | 策略只选择合法动作；不复制或绕过牌型/比较/轮转裁决                                            |
| 信息公平         | BotView 投影、import 审计、运行时泄漏测试                                                   | 不读取对手手牌、牌堆、seed 或隐藏评估；公开推断标注来源和置信度                               |
| 整手结构识别     | 三种结构来源；天然/逢人配对子和炸弹、四王炸、自然/逢人配顺子、三连对、钢板、三带二、同花顺  | 实体牌归属和 wildcardAs 正确；三张/散牌/控制/回收齐全；可能组合与已选方案不混淆               |
| 整手组牌方案     | 最佳结构、最少手数、保守控制、助攻配合四类方案、Top-N 排序和重复运行                        | 预计手数、完整度、逢人配、低散单、控制/回收、roleFit、finishability、DeadHandRisk 正确且稳定  |
| 候选覆盖         | 领出/跟牌的三连对、钢板、合理逢人配、同花顺、四王炸及普通牌型                               | 应有牌型均可生成并经规则引擎验证；无界子集枚举被禁止                                          |
| 动作后评估       | 对每个候选模拟移除实体牌并重新分析/组牌                                                     | 输出动作前后总手数、完整组合、散单、弱对子、控制/回收与三项质量指标差值                       |
| 逢人配机会成本   | 自然替代与逢人配低对子/小炸弹对照                                                           | 自然对 J/Q 优先于逢人配对 6；天然 8888 优先于两逢人配 5555；尾局例外有解释                    |
| 组合破坏         | 炸弹、同花顺、钢板、三连对、顺子、三带二、对子拆分对照                                      | 普通局面拆天然炸弹接近软禁止；所有惩罚与例外均可解释                                          |
| 控制资源预算     | 手牌多/少、低散单多/少、最后控制牌和高威胁局面对照                                          | 不因低威胁耗尽王/级牌/A/高对子/高三张/炸弹/同花顺；至少保留一个必要回收点；尾局例外正确       |
| 争夺价值         | 同一可压局面改变对手威胁、队友需要、结构损失、资源成本和后续路线                            | 低威胁高成本且无后续时过牌；高威胁或明确路线时争夺；无固定 must-contest 极值                  |
| 后续路线         | 压住后至少一手领出规划                                                                      | 输出下一手、预计手数变化、控制保持和连续出完路线；无路线时明确降权                            |
| 公开记牌         | 累计公开出牌/过牌后重复决策                                                                 | 关键牌、牌型历史、过牌倾向和余牌数实际改变局面/争夺评分                                       |
| 专家牌例         | [expert-scenario-catalog.md](expert-scenario-catalog.md) 分批 S01—S50、S51—S75、S76—S100    | P2.5A 首批 50 例及九类错误全部通过；P2.5C 达到规范八类 100 例且旧例不回退                     |
| 自动对局专项指标 | 固定 seed 10,000 局、普通/专家对测                                                          | 输出 9 项专项率、头游率、双上率、完成率、非法动作、失败 seed 和平均/P95；阈值在最终样本前冻结 |

| 策略扩展/版本    | 注册表、profile、示例新增规则和版本快照                                                     | ID 唯一、稳定排序、配置完整；新增规则不改评分主流程；不污染规则状态/存档                      |
| 证据与成熟度     | rules_based/expert_source/heuristic/needs_expert_validation × default_eligible/experimental | evidence 与 maturity 独立；experimental 不得进入默认 expert；解释显示证据等级                 |

## 阻断发布的八个反例

八个反例合计覆盖九类硬门槛：天然对子优先、天然炸弹保护、逢人配机会成本、不无意义拆炸、控制牌保留、DeadHandRisk、合理过牌、后续路线和尾局例外。规则数量、胜率或平均指标均不能抵消其中任一反例失败。

| 场景                                         | 必须结果                                               |
| -------------------------------------------- | ------------------------------------------------------ |
| S01/S02：自然对 J、Q 与逢人配 + 6 均可压对 5 | 选择最低必要天然对子，不组成对 6                       |
| S03：天然 8888 与两张逢人配 + 55             | 不制造 5555，保留天然炸弹和逢人配价值                  |
| S11：普通局面从 8888 拆 8 压单 5             | 选择过牌或不破坏结构的替代动作                         |
| S21/S22：仍有大量 2—7 低散牌且拟耗尽控制牌   | 保留至少一个必要回收点，低威胁动作降权                 |
| S31/S32：对手威胁低、压制成本高              | 允许并优先合理过牌                                     |
| S12/S34：对手只剩 1 张且必须拆牌阻断         | 允许高成本阻断，并解释尾局例外                         |
| S18/S19：候选即时价值接近但动作后余牌不同    | 比较预计手数、控制牌与 DeadHandRisk 后选择整体更优动作 |
| S39/S42：候选均能压住但下一手路线不同        | 奖励明确下一手；无路线输出 `noUsefulFollowUp` 并降权   |
