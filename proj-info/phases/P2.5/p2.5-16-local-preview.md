# P2.5-16 本地可试玩 Preview

normal 是默认机器人 profile。页面顶部的“机器人 Preview”仅用于本地验收：显式选择
“专家-24（Preview）”后，接下来的机器人回合使用真实 expert-24 决策入口；不会把
normal 默认值或提示入口默认值改为 expert。

生产构建的本地启动步骤：

```powershell
cd D:\MyWorks\card-game\frontend
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1 --port 4173
```

浏览器打开 `http://127.0.0.1:4173`。Preview 会显示机器人 profile、expert 思考状态和
最近一次实际决策耗时；该耗时不参与策略选择，也不改变 ADR-0023 的性能测量合同。
