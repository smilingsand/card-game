## 目标与边界

P2.5 将单人本地掼蛋机器人提升到熟练玩家至中高级玩家水平，优先消除明显不合理的出牌。修订后的核心不是给当前动作继续叠加常数，而是先生成高质量整手组牌方案，再比较每个动作执行后的余牌质量、控制资源、争夺价值和至少下一手路线。

继续保留以下边界：规则引擎唯一裁决合法性；机器人只使用己方手牌和公开信息；策略注册表/profile 可持续扩展；评分和解释可追溯；相同输入结果确定。阶段内不引入大模型、强化学习、蒙特卡洛搜索、后端或隐藏手牌采样。

## 试玩问题与计划修订

当前机器人会出现逢人配替代更高天然对子、用两张逢人配制造低价值小炸弹、拆天然炸弹接小单张、机械争夺、提前耗尽控制牌、留下大量低散单，以及没有压住后的下一手路线。这些问题已转化为独立组件和验收项：

- `HandStructureAnalyzer` 与 `HandPlanGenerator`；
- `PostActionHandEvaluator`；
- `ControlResourceEvaluator`；
- `ContestEvaluator`；
- `FollowUpPlanner`；
- 候选生成 2.0、首批 50 个固定专家牌例和九项自动对局专项错误指标。

## 当前代码审计摘要

| 问题               | 当前证据                                                       | P2.5 处理                               |
| ------------------ | -------------------------------------------------------------- | --------------------------------------- |
| 机械争夺           | `basic-bot.ts`/`normal-bot.ts` 对非队友最高牌直接大幅惩罚 pass | `ContestEvaluator` 综合收益与成本       |
| 局部结构判断       | 只按同点数组或少量单张特判惩罚拆牌                             | 动作后重新组牌和质量差值                |
| 逢人配低估机会成本 | 只处理“低配”，不比较天然替代与其他组牌用途                     | 天然/逢人配结构分离、机会成本与资源预算 |
| 缺少后续路线       | 当前只对当前动作打分                                           | `FollowUpPlanner` 至少前看一手          |
| 领出候选不足       | 缺三连对、钢板、合理逢人配、同花顺、四王炸                     | 候选生成 2.0                            |
| 自动对局失真       | 只生成单张，`publicEvents` 为空                                | 复用牌桌候选并累计公开事件              |

## 已确认决策

- P2.5A 以 30—40 条核心规则、50 例、九类已知错误覆盖和独立发布为门槛；B 深化整手/动作后/控制/后续路线；C 补记牌/协作/对手倾向并达到 100 例。
- P2.5A 验收后，机器人与提示默认共用 `expert` profile；`normal` 保留作回归、对照和调试。
- 专家预算为平均 ≤100ms、P95 ≤250ms；优先缓存、Top-N、增量计算和确定性早停，达到明确触发条件后才用 Web Worker。
- 后续能力使用 Bot-AI 2.0—5.0 独立编号。
- 策略同时标注证据 `evidence` 和成熟度 `maturity`；`needs_expert_validation` 通过七项资格门禁后可进默认 expert，`experimental` 只能进实验 profile。

完整冻结内容见 [implementation-plan.md](implementation-plan.md#12-已确认的设计决策)。
