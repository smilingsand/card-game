# P2.5 专家固定牌例目录

> 本文件定义 P2.5A 首批 50 个场景，并给出 P2.5B/C 补齐至长期 100 例的目录。P2.5-03 已将 S01-S50 的机器可读基线落在 `frontend/src/games/guandan/expert-fixtures.ts`：每例都有完整己方实体手牌、级牌、仅公开局面、目标/合法上下文、推荐/拒绝/允许备选动作，以及结构、动作后、控制、争夺、后续路线和解释断言。fixture schema 当前为 v1；它不携带对手隐藏手牌，后续 runner 必须先调用规则引擎验证动作。

## 最低验收

- S01、S03、S11、S21、S31、S34、S18 和 S39 是八个阻断发布反例；合计必须覆盖天然对子优先、天然炸弹保护、逢人配机会成本、不无意义拆炸、控制牌保留、DeadHandRisk、合理过牌、后续路线和尾局例外九类硬门槛。
- 至少 50 例全部验证确定性、信息公平和合法动作边界。
- 新增专家资料时，可追加场景，既有 ID 不复用、不静默改写期望；变更需记录理由和策略/profile 版本。

## P2.5B/C：S51—S100 新增目录建议

为达到设计规范的八类 100 例配额，S01—S50 在 fixture 落地时为每例指定唯一“主分类”；S47/S48 归入复杂组牌与逢人配覆盖。后续按下表补齐：

| 新增 ID  | 主分类         | 新增数量 | 重点边界                                               |
| -------- | -------------- | -------: | ------------------------------------------------------ |
| S51—S63  | 组牌与逢人配   |       13 | 多用途逢人配、四类 HandPlan、自然/逢人配顺子、角色适配 |
| S64—S71  | 炸弹与结构保护 |        8 | 四王炸、同花顺、不同长度炸弹、软禁止与尾局例外         |
| S72—S75  | 动作后剩余手牌 |        4 | 增量重算等价、预计手数、完整组合、DeadHandRisk 临界值  |
| S76—S81  | 是否争夺牌权   |        6 | 威胁/成本交叉、合理过牌、无后续、队友更适合接牌        |
| S82—S88  | 队友协作       |        7 | 送牌、让牌、接风、主攻/助攻转换、双上保护              |
| S89—S96  | 对手尾局阻断   |        8 | 对手 1/2/5 张、单/对/顺子/三带二防守与结构牺牲         |
| S97—S100 | 公开记牌       |        4 | 王/级牌/逢人配计数、炸弹风险、过牌概率与置信度         |

P2.5B 先交付 S51—S75，P2.5C 再交付 S76—S100。最终主分类配额必须为：组牌与逢人配 25、炸弹与结构保护 15、动作后剩余手牌 15、控制牌保留 10、是否争夺 10、队友协作 10、对手尾局阻断 10、公开记牌 5。
