# P1-19D：重新开赛与重开本局

状态：accepted（2026-07-15）

## 范围

- 将原“新局”与“清除存档”合并为“重新开赛”：以新的空赛局覆盖本地存档，双方等级从 2 开始。
- 新增“重开本局”：保留上一局完成顺序、双方等级和本局级牌；使用新的随机 seed 重新发当前局，并用新手牌重新计算进贡、抗贡与首家。
- 重开本局会清除当前局出牌、人工理牌偏好和当前局完成顺序；机器人可自动处理的贡/还贡仍会按新牌立即完成。

## 验收证据

- 固定牌例：重开本局后局号、上局完成顺序、等级和级牌保持不变；随机 seed、手牌和贡牌计划更新；存档可恢复。
- 组件测试：标题栏仅显示“重新开赛”、“重开本局”，不再显示“清除存档”。
- 定向：`npm.cmd run test:run -- src/games/guandan/table-session.test.ts src/App.test.tsx`，22 项通过。
- 全量：`npm.cmd run test:run`，19 个文件 / 97 项通过（含 1,000 局自动对局）。
- `npm.cmd run typecheck`、`npm.cmd run lint`、`npm.cmd run build` 均通过。
