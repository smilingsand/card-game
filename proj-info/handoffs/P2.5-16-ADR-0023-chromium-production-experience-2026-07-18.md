# P2.5-16 ADR-0023 Chromium 生产构建体验确认（2026-07-18）

## 范围与方法

- 构建：独立 Vite production bundle（`browser-performance.html`），不是 dev server，且不加入应用默认入口。
- 浏览器：Chromium，通过 Playwright CLI 打开本机 `vite preview` 的 production 输出。
- 会话：三个全新的命名 Chromium 会话，分别为 `p25browser1`、`p25browser3`、`p25browser4`；每次打开后均先执行 snapshot，再调用测量 API。
- 固定代表性 `BotView`：ADR-0020 已冻结的 seed=0 actionIndex `0`（开局/Top-20 慢例）、`44`（中局/Top-20 慢例）、`114`（尾局/mandatory）。测量入口在同一浏览器内以既有 expert 路径重放并捕获这些只读 `BotView`，清空精确缓存后测量从 `chooseExpertBotDecision` 请求到动作返回。
- 未更改策略、深度预算、normal profile、合法动作、Worker 或超时行为；没有运行 100 局。

`elapsedMilliseconds` 是决策调用同步占用主线程的准确时长，故同时作为“请求到动作返回”和“该请求的主线程阻塞”指标。`PerformanceObserver(longtask)` 的回调可跨 task 延迟投递，不能可靠归属到单个候选请求；其原始观察仅作诊断，未用于下面的判定。

## 三个新会话原始结果

| 会话        | actionIndex=0 | actionIndex=44 | actionIndex=114 | 会话平均 | JS heap used / total |
| ----------- | ------------: | -------------: | --------------: | -------: | -------------------: |
| p25browser1 |      1161.8ms |          1.1ms |           1.1ms |  388.0ms |  292.4MiB / 392.7MiB |
| p25browser3 |      1178.9ms |        634.4ms |         220.3ms |  677.9ms |  317.5MiB / 372.6MiB |
| p25browser4 |      1186.3ms |        625.8ms |         222.3ms |  678.1ms |  309.4MiB / 376.0MiB |

34 个固定样本的完整质量对照仍由 ADR-0022 持有；本浏览器体验合同只要求固定代表性样本，而非把浏览器会话冒充 Node 的 34 样本回归门禁。

## 聚合与结论

| 指标                  |     结果 |          产品体验阈值 | 结论   |
| --------------------- | -------: | --------------------: | ------ |
| 三会话平均值中位数    |  677.9ms |          仅作体验观察 | 记录   |
| pooled P95（9 次）    | 1186.3ms |               <= 1.5s | 通过   |
| 全局最慢              | 1186.3ms |                 <= 4s | 通过   |
| 最大观测 JS heap used | 317.5MiB | 本 ADR 未冻结数值门禁 | 已记录 |

因此，ADR-0023 的 Chromium production build 产品体验确认在上述三种代表性固定 `BotView` 范围内通过。该结论不替代 Node/tsx 的 34 样本自动化门禁，也不把浏览器并行化或缓存命中当作单次决策性能改善。
