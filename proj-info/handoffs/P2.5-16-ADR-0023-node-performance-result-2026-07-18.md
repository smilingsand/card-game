# P2.5-16 ADR-0023 Node/tsx 可重复性能结果（2026-07-18）

## 合同执行

Node 自动化主门禁使用五个相互独立的 `node --expose-gc --import tsx` 进程。
每个进程先重放 ADR-0020 的 seed=0 历史路径；重放只用于取得冻结的
BotView，之后清空所有可观察的精确缓存。

每个进程按以下三层执行：

1. `processColdStart`：首个 non-fixed expert BotView（actionIndex=30），仅诊断；
2. 三个 non-fixed expert BotView（actionIndex=34、38、42）不计时预热，随后执行
   一次显式 GC；
3. `steadyStateCold`：34 个 ADR-0020 固定 BotView，此前未作为本进程的决策输入；
   再立即重复相同 34 个 BotView 得到 `warm`。

单次决策之间未执行 GC。每个 steady-state cold 轮结束时 decision cache 的命中数为
0；暖轮结束时新增 34 次命中，证明两轮边界正确。首个进程冷启动的五次结果为
51.47–61.16ms，明确不参与门禁。

## 主门禁（170 个 steady-state cold 样本）

| 指标                   |       结果 |      门槛 | 判定 |
| ---------------------- | ---------: | --------: | ---- |
| 五个进程冷均值的中位数 |   162.95ms |   <=500ms | 通过 |
| pooled cold P95        | 1,037.93ms | <=1,500ms | 通过 |
| 全局最慢 cold 决策     | 1,910.73ms | <=4,000ms | 通过 |
| warm P95               |     4.52ms |   <=400ms | 通过 |

各进程 steady-state cold 平均值为 161.57、168.65、162.95、158.27、168.78ms；
未选择任意单进程结果作为验收依据。

最慢样本为固定 actionIndex=0（3,864 semantic candidates），其 FollowUp 为主要耗时。
170 个 cold 样本的模块累计耗时中，FollowUp 为 19,544.99ms，PostAction 为
1,452.10ms，FollowUp lead catalogue 为 3,185.09ms。五个进程的峰值 RSS 最大值为
340,963,328 bytes，峰值 heapUsed 最大值为 166,133,144 bytes；没有 LRU 淘汰。

## 结论与边界

ADR-0023 的 Node/tsx Stage 1 主性能门禁通过。Vitest 不作为本门禁证据。
本记录未运行 100 局，也未启动 P2.5-17；浏览器生产构建的三个全新 Chromium 会话
体验确认仍是 ADR-0023 的独立待办。
