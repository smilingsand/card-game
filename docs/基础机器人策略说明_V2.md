# 基础机器人策略说明 V2

> 状态：normal-vNext 是当前唯一产品策略（2026-07-22）。本文中 P2.5 expert
> 规划为历史资料，已撤销；恢复须遵循 ADR-0024。
>
> 本文用于让玩家、测试者和开发者对照机器人“现在会怎样出牌”以及“P2.5 将新增什么能力”。它不是掼蛋强制规则，也不宣称机器人已经达到最优或职业水平。所有规则裁决仍以 `docs/resolved-rules.md` 为准。
>
> `docs/Guandan_Expert_Bot_Design_Specification_v1.0.md` 是 P2.5 最高级设计依据；本文是面向玩家和开发者的策略对照说明，不替代该规范。

## 1. 阅读方式与状态标记

本文中的每项策略均标记状态：

- **已实现**：当前牌桌和“提示”功能实际会使用。
- **已实现（基础层）**：已在基础策略实现；当前普通策略在领出时复用它。
- **P2.5 计划**：已纳入阶段计划，但尚未写入生产决策代码。
- **不采用**：明确不属于本阶段能力。

P2.5 的目标是把机器人提升到熟练玩家至中高级玩家水平，优先避免明显不合理的出牌；它不是求解器，也不会以隐藏信息作弊。

## 2. 信息边界与共同入口

机器人和真人“提示”使用同一条策略入口。可读取的信息仅包括：

- 自己的完整手牌；
- 已公开的出牌和过牌事件；
- 四家公开剩余牌数；
- 当前级牌、领出者、当前最高牌；
- 规则引擎已验证的合法动作集合。

机器人不得读取对手真实手牌、牌堆顺序、洗牌 seed 或隐藏评估。策略只能从合法动作集中选一个动作，提交后仍必须经过统一的规则校验与应用。

## 3. 当前决策流程

```text
候选牌组生成
  -> 牌型识别与规则引擎筛选
  -> BotView（己方手牌 + 公开信息 + 合法动作）
  -> 当前基础/普通策略评分
  -> 稳定并列裁决
  -> validateAction / applyAction
```

当前牌桌使用“普通策略”：领出时复用基础策略；跟牌时在基础原则上增加保留炸弹、小王对子和自然顺子的处理。P2.5 会把中间的“当前基础/普通策略评分”替换为统一、可解释的专家策略评分链，见第 7 节。P2.5A 验收发布后，牌桌机器人和“提示”默认共用 `expert` profile；`normal` profile 继续保留作回归、对照和调试。

## 4. 当前已实现：候选动作范围

### 4.1 领出候选

**已实现。** 机器人会从自己的手牌中生成并交给规则引擎筛选：

- 每张单牌；
- 完整同点数组（对子、三张、4–10 张普通炸弹）；
- 不拆组的三带二；
- 不用逢人配补齐的自然顺子。

这是有意收窄的候选集：当前不会主动枚举所有三连对、钢板、含逢人配的复杂组合、自然同花顺或四王炸。规则引擎可以识别这些牌型；“不枚举”只是现有策略能力边界。

领出时，若手中还有非炸弹候选，机器人不会主动领出炸弹；只有剩余手牌全为炸弹，或该炸弹恰好能一次走完所有剩牌时，才允许领出炸弹。

### 4.2 跟牌候选

**已实现。** 桌面存在最高牌时，机器人枚举与当前最高牌张数相同的手牌组合，并额外枚举完整普通炸弹，再由规则引擎判断是否构成可压制的同型牌、炸弹或同花顺。候选集同时含有合法的“过牌”。

因此当前机器人可以跟对子、三张、三带二、顺子等，并不只会跟单张；但它尚未以专家策略方式完整枚举和评估所有复杂连续牌型。

## 5. 当前已实现：基础策略（V1 延续）

### 5.1 领出策略

| 策略                 | 状态             | 当前含义                                                                                                               |
| -------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 不拆完整同点组       | 已实现（基础层） | 从对子、三张或炸弹中抽走部分牌会受到极高惩罚。                                                                         |
| 低位短牌需有回收牌   | 已实现（基础层） | 低单、低对、低三张、低三带二若没有同型高牌可在后续夺回牌权，则显著降权；顺子及更长牌型不受此门槛限制，炸弹不算回收牌。 |
| 小牌优先             | 已实现（基础层） | 在拆组风险和回收条件相近时，优先较小的比较键。                                                                         |
| 多出牌优先           | 已实现（基础层） | 在前述条件相近时，优先张数较多的候选，以更快减少手牌。                                                                 |
| 非残局不低配红桃级牌 | 已实现（基础层） | 红桃级牌直接作为本级牌已可用时，不为压小牌解释成更低点数；残局例外。                                                   |
| 稳定并列裁决         | 已实现（基础层） | 完全同分按动作的固定字典序选择，确保相同局面可复现。                                                                   |

回收牌门槛的现有基线是：单张看 A/级牌/大小王；对子看 K/A/级牌对子；三张看 J/Q/K/A/级牌三张；三带二看高主三张并仍能组成完整三带二。拟出牌本身已达到相应高位时，不因缺少剩余回收牌降权。

### 5.2 跟牌、过牌与残局

| 策略               | 状态                   | 当前含义                                                                                  |
| ------------------ | ---------------------- | ----------------------------------------------------------------------------------------- |
| 队友压住时让牌     | 已实现                 | 当前最高牌属于队友且可过牌时，过牌具有极高优先级，避免无意义压队友。                      |
| 对手压住时机械争夺 | 已实现但确认有严重缺陷 | 对手压住且存在合法压制动作时，过牌被强烈惩罚；P2.5 将删除这一机械策略，改为争夺价值评估。 |
| 尾局拦截           | 已实现                 | 任意一家公开剩余牌数不超过 1 张时，提高非过牌、阻断动作的优先级。                         |
| 低代价压制         | 已实现（基础层）       | 多个压制动作中，优先不拆完整组、不低配级牌、少出牌、比较键较小的动作。                    |

### 5.3 当前普通策略增量

以下策略已在当前牌桌的普通策略跟牌路径中生效：

| 策略               | 状态   | 当前含义                                                                   |
| ------------------ | ------ | -------------------------------------------------------------------------- |
| 同型可压时保留炸弹 | 已实现 | 若存在非炸弹的合法压制，通常不使用炸弹；对手尾局威胁时可例外。             |
| 保留小王对子       | 已实现 | 同时持有大王和两张小王、需要用单张压 A 时，优先出大王，保留小王对子。      |
| 保留自然顺子       | 已实现 | 有王可用且待出的单牌属于完整自然五张顺子时，优先出王而不拆顺子。           |
| 简单阶段理由       | 已实现 | 根据自己手牌数标记开局/中局/残局并输出原因；当前并非完整的分阶段权重系统。 |

## 6. 当前能力边界

以下内容当前**尚未**进入实际动作评分：

- 公开记牌的完整使用：虽然已记录全部公开动作，且已有高牌统计与攻/助攻分析模块，但它们未接入当前生产决策；
- 基于公开出牌/过牌历史的牌型倾向、关键牌剩余数、炸弹风险推断；
- 队友将出完时的送牌、队友接风时让先、队友弱时承担控制等深入协作；
- 对手剩 2/3 张时按单张、对子、顺子或三带二等具体威胁精确阻断；
- 统一评估领出和跟牌的局面特征、动作特征及分阶段权重；
- 所有复杂连续牌型、逢人配组合、同花顺和四王炸的专家级候选评估；
- 多步搜索、蒙特卡洛模拟、强化学习或大模型决策。

实际试玩进一步确认了以下严重缺陷：机器人可能用逢人配制造低对子/小炸弹而忽略天然组合；拆天然炸弹接低单张；为低威胁对手机械争夺；过早耗尽王、级牌、A 和高对子；留下大量没有回收牌的 2–7 低散单；以及完全不比较压住后的下一手路线。以下修订后的 P2.5 计划专门解决这些问题。

## 7. P2.5 计划：专家策略知识库与评分系统

> 以下内容均为 **P2.5 计划**，不是当前已经生效的出牌能力。

### 7.1 修订后的目标决策链

```text
规则引擎合法动作
  -> HandStructureAnalyzer（识别整手所有可能组合与资源）
  -> HandPlanGenerator（生成若干高质量整手分组方案）
  -> SituationAnalyzer（公开记牌转局面特征）
  -> ContestEvaluator（判断牌权是否值得争夺）
  -> ActionFeatureExtractor（提取候选即时特征）
  -> PostActionHandEvaluator（动作后重新组牌并评价余牌）
  -> ControlResourceEvaluator（评估控制牌预算与机会成本）
  -> FollowUpPlanner（至少规划取得牌权后的下一手）
  -> ExpertStrategyKnowledgeBase（命中结构化策略）
  -> ActionScorer（汇总评分）
  -> ActionSelector（稳定选择）
  -> DecisionExplanation（调试解释）
```

策略总分将由下列可追溯分项构成：

```text
总分 = 即时出牌价值 + 动作后手牌结构 + 出完难度
     + 争夺价值 + 控制资源预算 + 后续路线
     + 队友协作 + 公开记牌 + 专家规则修正
     - 逢人配机会成本 - 组合破坏惩罚 - 死手风险
```

### 7.2 HandStructureAnalyzer：识别整手结构

**P2.5 计划。** 对自己的完整手牌识别并区分：

- 天然炸弹、逢人配炸弹与四王炸；
- 天然对子与逢人配对子；
- 自然/逢人配顺子、三连对、钢板、三带二、三张和同花顺；
- 散单、2–7 低散单和弱对子；
- 王、级牌、红桃级牌、A、高对子、高三张、炸弹、同花顺等控制牌；
- 可在后续重新取得牌权的回收牌。

同一实体牌可以属于多个可能组合，但只有在具体整手方案中才会确定其用途，不能被同时重复计算。

### 7.3 HandPlanGenerator：生成整手组牌方案

**P2.5 计划。** 生成若干确定性的高质量整手分组方案，而不是用一个局部贪心结果代表整手。每个方案计算：预计总手数、结构完整度、天然炸弹、逢人配占用、低散单、弱对子、控制牌、回收能力、`finishability` 和 `deadHandRisk`。

首版采用有界 Top-N/束搜索，不穷举所有组合，并至少形成最佳结构、最少手数、保守控制、助攻配合四类候选方案。相同手牌、级牌和策略 profile 必须得到相同方案及排序。

### 7.4 SituationAnalyzer：公开局面特征

**P2.5 计划。** `SituationAnalyzer` 仅从允许的公开信息得出：

- 开局、中局、残局；
- 四家余牌数、己方预计手数、队友/对手的出完威胁；
- 大小王、级牌、逢人配及高价值控制牌的公开已出/可能剩余情况；
- 每位玩家公开出过的牌型和对哪些牌型频繁过牌的历史；
- 当前控制权归属、队友/对手是否领出；
- 主攻、助攻或均衡角色，以及该推断的置信度和原因。

“可能”“倾向”和“威胁”均是可解释的公开信息推断，不是读取对手真实手牌。

### 7.5 ContestEvaluator：判断是否值得争夺

**P2.5 计划。** 删除“对手有合法可压动作就强烈惩罚过牌”的当前策略。每次争夺综合：对手威胁、队友需要、压制收益、结构损失、控制资源成本、动作后死手风险和压住后的后续价值。

实现采用两阶段：先建立对手威胁和队友需要的争夺上下文；得到动作后余牌、控制资源和下一手方案后，再完成该候选的最终争夺值，避免循环依赖。

对手威胁低、压制成本高且压住后没有好路线时，应允许过牌；对手仅剩 1 张、队友需要救援或可以直接形成出完路线时，允许高成本争夺。

### 7.6 ActionFeatureExtractor 与 PostActionHandEvaluator

**P2.5 计划。** `ActionFeatureExtractor` 描述动作即时事实：张数、牌型、压制对象、牌权变化、阻断效果、逢人配解释及其对应 hand plan。

`PostActionHandEvaluator` 会为每个候选模拟移除实体牌并重新分析/组牌，比较：

- 动作前后预计总手数；
- 天然/逢人配炸弹和其他完整组合；
- 低散单和弱对子；
- 控制牌和回收牌；
- `structuralIntegrity`、`finishability`、`deadHandRisk` 的变化。

组合破坏必须以动作前后差值为依据：普通局面拆天然炸弹接近软禁止；拆同花顺、钢板、三连对、顺子、三带二和对子分别计价，并保留直接出完或阻止仅剩 1 张对手等明确例外。

### 7.7 ControlResourceEvaluator：控制牌预算

**P2.5 计划。** 将王、级牌、红桃级牌、A、高对子和炸弹视为分层控制资源。手牌仍多、有多个低散单或该牌是最后控制资源时，提高消耗代价；尾局直接出完、阻断高威胁对手或救援队友时允许例外。

机器人必须避免打光所有控制牌后留下大量 2–7 散单，并保留足够的同型回收牌。

### 7.8 FollowUpPlanner：至少前看一手

**P2.5 计划。** 对每个可能取得牌权的动作，规划下一手准备出的牌型与实体牌，评价是否继续减少预计手数、保持控制或形成连续出完路线。压住后没有合理下一手时输出 `noUsefulFollowUp` 并降低争夺价值。

该层只看自己的下一手，不采样对手隐藏手牌，也不做蒙特卡洛模拟。

### 7.9 逢人配机会成本

**P2.5 计划。** 逢人配不再只有“是否低配”的固定惩罚，而是比较它在所有高质量 hand plan 中的其他用途：

- 有自然对子可压时，不用逢人配组成更低对子；
- 有天然炸弹时，不用逢人配制造更小炸弹；
- 普通局面不使用两张逢人配制造低价值四炸；
- 每使用一张逢人配都计算动作前后最佳组牌方案的机会成本；
- 尾局直接出完或阻止高威胁对手时允许例外。

### 7.10 规划中的完整核心策略目录

以下 60 条均来自最高级设计规范，当前状态均为 **P2.5 计划**，不是已经生效的生产策略。P2.5A 先从中冻结 30—40 条核心反愚蠢规则；P2.5B/C 再以独立规则包补齐和深化。

#### 组牌策略（1—20）

1. 天然牌型优先于逢人配补型。
2. 自然对子优先于逢人配低对子。
3. 天然炸弹优先于逢人配小炸弹。
4. 逢人配优先用于显著减少总手数。
5. 逢人配优先用于高价值结构。
6. 使用两张逢人配需额外机会成本。
7. 不为压低牌破坏天然炸弹。
8. 不轻易拆顺子。
9. 不轻易拆钢板。
10. 不轻易拆三连对。
11. 不轻易拆完整三带二。
12. 优先减少无法回收的弱散单。
13. 避免产生孤立三张。
14. 避免产生大量弱对子。
15. 组牌方案应保留至少一个回收点。
16. 主攻方案优先减少总手数。
17. 助攻方案优先保留控制力。
18. 尾局可以牺牲结构直接出完。
19. 对手高威胁时可牺牲结构阻断。
20. 同一卡牌只能服务一个最终分组。

#### 控制牌策略（21—30）

21. 手牌较多时保留至少一个高单回收点。
22. 手牌较多时保留高对子回收点。
23. 不为低价值牌争夺消耗最后一张王。
24. 不连续打光王、级牌和 A。
25. 有多个低散单时提高控制资源价值。
26. 炸弹是控制资源，不是纯粹尾牌。
27. 取得牌权但无后续时降低动作价值。
28. 保留能够收回当前弱路的同型大牌。
29. 尾局阻断可提高控制牌使用意愿。
30. 可直接走完时允许消耗全部控制牌。

#### 是否争夺（31—40）

31. 对手余牌多且当前威胁低时允许过牌。
32. 对手剩 1 张时优先封锁单张。
33. 对手剩 2 张时重点防对子。
34. 对手剩 5 张时重点防顺子和三带二。
35. 队友压住时非必要不过度接牌。
36. 队友即将出完时优先送牌。
37. 压制需拆炸时必须提高争夺门槛。
38. 压制会耗尽控制牌时必须提高争夺门槛。
39. 压住后无后续路线时降低争夺价值。
40. 队友明显无力时自己承担控制。

#### 公开记牌（41—50）

41. 统计大小王已出数量。
42. 统计级牌已出数量。
43. 统计红桃级牌已出数量。
44. 判断四王炸是否仍可能存在。
45. 判断更大炸弹风险。
46. 记录每家主动领出的牌型。
47. 记录每家压制过的牌型。
48. 记录每家频繁过牌的牌型。
49. 过牌只形成概率推断。
50. 已出大牌多时提高中高牌安全度。

#### 队友协作（51—60）

51. 不无意义压队友。
52. 队友剩少量牌时尝试送其可能需要的牌型。
53. 队友取得控制时尽量让牌。
54. 队友明显主攻时自己转助攻。
55. 队友牌弱时自己承担控制。
56. 队友接风时避免抢先。
57. 队友只剩一手时优先保护其出完。
58. 不因自己局部收益破坏本队双上机会。
59. 队友连续出某牌型时提高该牌型倾向。
60. 队友行动推断必须带置信度。

每条实际规则必须包含永久 ID、版本、适用阶段、条件、例外、优先级、分数修正、解释、证据等级、成熟度、固定牌例和单元测试。新增教材、PDF、文章或实战牌例后，还要补充来源页码。

证据和成熟度是两个独立维度：

- `evidence`：`rules_based`、`expert_source`、`heuristic` 或 `needs_expert_validation`；
- `maturity`：`default_eligible` 或 `experimental`。

`needs_expert_validation` 规则只有在具备明确牌理、至少一个固定牌例、命中/未命中/例外测试、不冲突冻结规则、自动对局/回归无明显异常、可单独关闭且解释显示证据等级时，才能以 `default_eligible` 进入默认专家 profile。`experimental` 规则只能进入实验 profile。

### 7.11 可扩展策略库

**P2.5 计划。** 每条策略将成为独立、无副作用的规则模块，包含永久 ID、版本、适用阶段、条件、例外、优先级、分数修正、解释与证据等级。规则注册表负责校验 ID 唯一、稳定排序与启停配置；评分器只消费统一接口。

因此，后续新增策略的标准步骤是：新增规则文件、注册、补来源和例外、补单规则测试及固定牌例；不需要重写评分主流程。策略 profile 分为默认 `expert`、实验 `experimental` 和回归 `normal`，分别保存规则启停与阶段权重。规则冲突时全部保留为可解释的评分修正，而非后写规则静默覆盖前者。

策略规则和 profile 的版本会进入基准报告、固定牌例快照和调试解释；它们不是规则事实，不会写入 `TurnState`、事件流或存档。若未来需要恢复未完成牌局时仍严格复现旧策略，必须先通过 ADR 设计独立的版本化会话配置。

### 7.12 可解释决策、100 牌例路线与专项指标

**P2.5 计划。** 调试模式会显示每个候选的总分、各评分项、命中规则和最终选择原因；关闭调试不会改变动作，也不会把解释写进存档或事件流。

P2.5A 首批固定专家牌例为 50 个，必须覆盖天然组合优先、逢人配机会成本、拆天然炸弹、控制牌预算、低威胁过牌、高威胁阻断、动作后死手风险和下一手路线。P2.5B/C 分两批补齐至规范长期 100 例。目录见 `proj-info/phases/P2.5/expert-scenario-catalog.md`。

固定 seed 的 10,000 局自动对局除合法性、确定性、本队头游率和双上率外，还统计：无必要拆天然炸弹率、逢人配低价值使用率、有自然炸弹仍制造小炸弹率、手牌较多时控制牌耗尽率、动作后低散单增加率、高成本无意义压制率、高 DeadHandRisk 形成率、队友压住时无意义接牌率和尾盘阻断成功率。

性能不再统一要求 10ms：基础机器人平均 ≤10ms，普通机器人平均 ≤30ms，专家启发式机器人平均 ≤100ms 且 P95 ≤250ms，最终口径由 ADR 在固定桌面/移动样本上冻结。专家层通过确定性 Top-N、固定候选束宽、手牌/方案/动作后/后续路线缓存、动作后增量重算和可证明不会胜出的劣质动作早停控制成本，不按墙钟时间随机中断搜索。只有真实样本出现主线程卡顿或超预算时才引入 Web Worker，且同步与 worker 决策必须一致。

### 7.13 P2.5 分阶段范围

| 范围        | 交付重点                                                                             |
| ----------- | ------------------------------------------------------------------------------------ |
| P2.5A 必须  | 完整决策链、30—40 条核心反愚蠢规则、S01—S50、9 项错误指标、解释、性能和 profile 回滚 |
| P2.5B 增量  | 组牌/控制规则深化、S51—S75、增量性能优化和按需 worker 验证                           |
| P2.5C 增量  | 协作/阻断/记牌深化、S76—S100、完成规范八类 100 例配额                                |
| 后续 Bot-AI | 独立编号的增强记牌、伙伴意图或另经 ADR 批准的研究能力；仍受信息公平边界约束          |

独立机器人能力版本为：Bot-AI 2.0 专家启发式、2.1 增强公开记牌、2.2 队友意图、3.0 隐藏信息采样研究、4.0 蒙特卡洛或有限搜索研究、5.0 离线强化学习研究。Bot-AI 3.0 及以后均不属于 P2.5，必须另立 ADR，也不得以“采样”为名读取对手真实手牌。

## 8. 非目标与安全约束

本版本和 P2.5 均不做：

- 重写规则引擎或改变已冻结规则；
- 使用对手手牌、牌堆或 seed；
- 大模型、强化学习、蒙特卡洛搜索或云端决策；
- 让策略模块绕过合法动作生成、规则校验或统一出牌入口；
- 将启发式策略误写成掼蛋强制规则。
