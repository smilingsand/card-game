# 基础机器人策略说明 V2

> 当前产品策略：普通 normal-vNext。P7-00 至 P7-23 的策略收敛已于 2026-08-27 完成 Vercel Preview/Production 验收；P2.7（2026-07-23）为其历史稳定化基线。
> normal-v1 仅保留为离线历史对照；P2.5 expert-24 已撤销为 Git 历史，恢复必须先新增 ADR。

## 1. 边界与动作合同

机器人和南家“提示”共用 normal-vNext 决策入口，只读取自己的手牌、公开事件、各座剩余张数、级牌和规则层生成的 `legalActions`。不读取对手手牌、牌堆顺序、随机 seed 或隐藏评估。

策略只能排序和选择 `legalActions`；规则层仍负责牌型识别、合法性校验和动作应用。跟牌没有可压制动作必定过牌；领牌必定选择一手合法出牌；只有规则层给出空动作集才允许返回未决错误。

## 2. 跟牌与争牌

- 同牌型普通响应按 `responseCost` 排序：点数、结构损伤、控制资源、逢人配机会成本与三带二附带对子成本。
- 中小自然对子、三张、三带二有明确的减手收益和争牌收益：22 对 66、444 对 888、44422 对 88866 在普通局面优先接牌。
- 高价值三带二（例如 AAAKK、主三张为级牌的 222AA）在普通局面优先过牌。
- 队友持权时默认不抢牌，直接出完例外。
- 天然四张及以上同点数炸弹绝不拆分；不为普通小牌拆炸弹、顺子、连对或钢板。

## 3. 下家尾局阻断

下家剩余 1～6 张时，根据公开剩余张数建立保守的可能牌型集合。领牌避免用小牌给下家顺走，同风险时由大到小。若任一对手剩余不超过 6 张且己方有至少两副完整天然炸弹，则主动整副炸弹夺回牌权；该判断不读取或推断对手手牌。

下家剩余 1～3 张且敌方持权时，夺回牌权优先于常规结构保护：可拆结构，且仅当炸弹是唯一合法压制时才用炸弹。该策略不删除合法动作；没有压制时仍过牌。

## 4. 控制资源保护

开中局的资源使用顺序从低到高为：

`普通自然小牌 → 普通自然中牌 → 拆普通低价值结构 → A/普通级牌 → 红桃级牌 → 小王 → 大王`

对应成本：A 120、普通级牌 140、红桃级牌 220、小王 300、大王 360；红桃级牌另有 120 的逢人配机会成本。

- 普通对子存在时，三带二附带对子优先普通、较小、独立对子；不用级牌、红桃级牌或王。
- 有普通三张时，不用红桃级牌补成小三张；红桃级牌不补小对子或低价值三带二。
- 对手出小单、小对时，优先普通低成本牌，不轻易使用级牌或王。
- 仅在直接出完、下家尾局强制阻断，或没有更低成本合法选择时消耗控制资源。
