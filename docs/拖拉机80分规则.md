## **一、游戏概述**

升级，又叫80分，拖拉机，双升或[双抠](https://zhida.zhihu.com/search?content_id=257130998\&content_type=Article\&match_order=1\&q=%E5%8F%8C%E6%8A%A0\&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODQwMTgxMDgsInEiOiLlj4zmiqAiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTcxMzA5OTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.cwhS_G5_hLGEO11457boxhIC7v-ftXs0yViTMLvvYvE\&zhida_source=entity)，是一种四人扑克牌对抗游戏。四位玩家分为两队，对家为同一队。游戏的目标是通过抓取分牌和抠底得分，不断升级，最终率先达到最高级别（A牌）的队伍获胜。

### **二、牌具与人数**

- **人数**：4人，分为两队。
- **牌数**：使用两副扑克牌，共108张，包括大小王。

### **三、分值与牌型**

- **分牌**：
- 5：每张5分
- 10和K：每张10分
- 总分：两副牌共200分
- **牌型**：
- 单张、对子、连对（拖拉机）等

### **四、主牌、副牌与[级牌](https://zhida.zhihu.com/search?content_id=257130998\&content_type=Article\&match_order=1\&q=%E7%BA%A7%E7%89%8C\&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODQwMTgxMDgsInEiOiLnuqfniYwiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTcxMzA5OTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.IFS2A0pNPN4Rr1SIJ6rCCTTiGK84FvkYjI3pY3CvuH0\&zhida_source=entity)**

- **主牌**：在本局游戏中，被特别指定为“主”的牌。包括：
- 大小王（无花色）
- 当前局次的**级牌**（无论花色）
- [主花色](https://zhida.zhihu.com/search?content_id=257130998\&content_type=Article\&match_order=1\&q=%E4%B8%BB%E8%8A%B1%E8%89%B2\&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODQwMTgxMDgsInEiOiLkuLvoirHoibIiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTcxMzA5OTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.vJF2vno-hptu-U6SHhHZRsPMlZpHC9Io4zA7UiLbcuU\&zhida_source=entity)的所有牌（即定主时确定的花色的牌）
- **副牌**：除了主牌以外的其他所有牌。

### **什么是级牌？**

- **级牌是当前庄家队伍的等级对应的牌点数**。
- 比如：当前庄家是**6级**，那么所有点数为6的牌（不论红桃6、方片6、黑桃6、梅花6）都是**级牌**。
- 级牌在每一局中自动作为主牌的一部分（即使不是主花色，也算主牌）。

### **级牌与升级的关系**

- 游戏开始时双方从**2级**起步。
- 随着比赛进行，根据得分结果，庄家队伍逐步向A（14级）升级。
- 当前的**级数决定了本局的级牌**。 例：
- 庄家是8级，本局级牌是8，所有的8点牌都是主牌。
- 达到A之后继续赢牌，则可以继续"反主"或直接赢得比赛。

### **五、游戏流程**

### **发牌与底牌**

- 每人发25张，剩余8张作为底牌。

### **确定庄家**

- 游戏开始时，由双方从2级起步。
- 上一局胜利的庄家继续当庄家。
- 如果闲家得分达到规定标准（80分及以上），则闲家反庄，成为新的庄家队伍。

### **亮主与定主（确定主花色）**

- 目的：确定本局使用的主花色（如红桃、黑桃等）
- 亮主规则：
- 在发牌过程中，任何玩家都可以通过亮出特定牌（级牌、王）来争夺主花色。
- 级牌由当前庄家等级确定，闲家也可亮出庄家等级对应的级牌确定主花色。
- 亮主的优先级（从低到高）：
- 单张级牌 < 一对级牌 < 一对小王 < 一对大王
- 主花色的确定：
- 最先亮出的花色为主花色。
- 后亮的玩家可以用更高优先级的牌强行改主，直至发牌结束。

### **扣底**

- 庄家拿到底牌后，再扣出8张组成新底牌。
- 闲家通过在最后一轮胜出扣底：
- 抠底时，如果底牌中有分牌（5、10、K），这些分会在被抠底时**分数翻倍**。
- 普通抠底（随便一张单牌赢最后一墩）：
- 底牌中的分牌（5、10、K）分值翻2倍。
- 对子扣底（用对子赢最后一墩）：
- 底牌中的分牌分值翻4倍倍。
- [拖拉机扣底](https://zhida.zhihu.com/search?content_id=257130998\&content_type=Article\&match_order=1\&q=%E6%8B%96%E6%8B%89%E6%9C%BA%E6%89%A3%E5%BA%95\&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODQwMTgxMDgsInEiOiLmi5bmi4nmnLrmiaPlupUiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTcxMzA5OTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.EpjNHXi_Oj6WME4isRW8-tTOTR6JEyG90j9Uic45TcA\&zhida_source=entity)（用连续对子赢最后一墩）：
- 拖拉机长度n对应分值翻 倍。
- 例子：
- 用2连对拖拉机（7♠7♠ + 8♠8♠）抠底，翻8倍。
- 用3连对拖拉机（7♠7♠ + 8♠8♠ + 9♠9♠）抠底，翻16倍。

### **出牌规则**

- 出牌顺序
- 庄家首先出牌。
- 每局后续由上一轮胜出的玩家出牌。
- 出牌要求
- 每轮首出玩家可以出任意牌型。
- 跟牌玩家需要遵循：
- 有首出花色的牌时，必须出首出花色的牌。
- **如果首出花色为副牌，且手上没有首出花色的牌，可以出主牌进行"[毙牌](https://zhida.zhihu.com/search?content_id=257130998\&content_type=Article\&match_order=1\&q=%E6%AF%99%E7%89%8C\&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODQwMTgxMDgsInEiOiLmr5nniYwiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTcxMzA5OTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.cJQ9O26fTVqfQ3Cmg8fq87PyTeVY096ANTOkUVsttPU\&zhida_source=entity)"或者出别的副牌进行“[贴牌](https://zhida.zhihu.com/search?content_id=257130998\&content_type=Article\&match_order=1\&q=%E8%B4%B4%E7%89%8C\&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODQwMTgxMDgsInEiOiLotLTniYwiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTcxMzA5OTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.x7vC5PIgUC7WibyOdSYcDRvqZYS5J9SzWJkOGka-kas\&zhida_source=entity)”**。
- 毙牌:
- 若首出花色为**副牌**花色，且手上**没有**首出花色的牌，用主牌强行压制对手。
- 出主牌毙牌的条件：
- 必须没有首出花色的牌，才能出主牌。
- 出的主牌，牌型必须与首出牌型匹配才能毙（如首出对子，用对子主牌才能毙；同理若是副牌拖拉机，也必须用拖拉机主牌才能毙）。
- 毙牌时，主牌在比较大小时，天然高于副牌，无论点数大小。
- 贴牌:
- 若首出花色为**副牌**花色，且手上**没有**首出花色的牌，可出别的副牌进行“贴牌”，“贴牌”永远是最小的。
- 若队友牌大，可通过贴副牌上的分来进行跑分（技巧性）。
- 特别注意
- 如果手上既有首出花色的单张，又有主牌，必须先打首出花色，不能直接用主牌毙。
- 拖拉机（连对）跟牌也需要跟出尽量完整的拖拉机，否则按最大可能跟出，例如没有拖拉机时候，但是有对子，得出对子。

### **得分与升级**

- 每轮由赢得该轮的玩家所属队伍收取分牌。
- 游戏结束后，结算分数，闲家得分0分，庄家升三级；得分40分以下，升两级；得分80分以下，升一级；得分80分，庄家下庄，闲家上庄不升级，得分120分，庄家下庄，闲家上庄升一级，以40分为一级类推。
- 新一局按最新级别打，新的级牌随之变化。

### **六、主牌与副牌的大小规则**

- 在任何情况下，主牌的大小都压制副牌，不论点数，但该情况一般发生在“毙牌”的时候。
- 主牌内部的大小顺序依次为：
- 大王最大，其次是小王，然后是主花色的级牌，再是其他花色的级牌，最后是主花色的普通牌。
- 主花色的级牌要比其他花色的级牌大，其他花色的级牌又比主花色的普通牌大。
- 主花色的普通牌之间按牌点大小比较，点数从小到大排列（2最小，A最大）。
- 副牌之间则仅按照点数大小比较，2最小，A最大，花色对大小没有影响。

### **七、拖拉机详细规则**

- 组成拖拉机必须满足：
- 花色一致。
- 点数连续。
- 每对都是两张相同点数的牌。
- 必须全部是主牌或全部是副牌，主副不能混合。
- 特别地，主牌内部：
- 小王和大王可以组成主牌拖拉机。
- 主花色级牌与副花色级牌可以连拖拉机（如果主花色是红桃，级牌是7，则红桃77 + 梅花/黑桃/方片77）。
- 主花色级牌与小王可以连拖拉机（如果主花色是红桃，级牌是7，则红桃77 + 小王小王）。
- 副花色级牌和小王**不能**组成拖拉机（如果主花色是红桃，级牌是7，则梅花/黑桃/方片77 + 小王小王不构成拖拉机）。
- 级牌相邻牌可以连拖拉机（如果主花色是红桃，级牌是7，则红桃66 + 红桃88，副牌也同理）。

### **八、胜负条件**

- 率先达到A（14级）的队伍获胜。
- 或者在约定时间/局数内，级别更高的一队获胜。

### **九、扩展**

- 该玩法可扩展到六人或者八人升级，六人升级对应4副牌，八人升级对应6副牌，相应的反庄升级分数需要调整。
